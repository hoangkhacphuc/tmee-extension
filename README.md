# Scribd Embed Link Converter

A cute, pastel-pink styled web tool to validate Scribd document links, extract the document ID, and generate direct embed links.

**Author**: Hoang Khac Phuc

## Features

- **Cute Pastel Aesthetic**: Soft pink theme with gentle gradients and rounded glassmorphism cards.
- **Instant Validation**: Verifies `scribd.com` links and handles format checks in real-time.
- **ID Extraction**: Automatically extracts the numeric Document ID (e.g. from `https://www.scribd.com/document/123456789/......`).
- **Direct Embed URL**: Generates `https://www.scribd.com/embeds/<DOC_ID>/content`.
- **New Tab Opener & One-Click Copy**: Seamlessly open the embed in a new browser tab or copy the URL to clipboard.
- **Zero Build Setup**: Directly runnable by opening `index.html` in any modern web browser.

## File Structure

- `index.html`: Main HTML file with embedded logic and semantic structure.
- `style.css`: Compiled CSS stylesheet with rem-based typography and pixel-based dimensions.
- `style.less`: LESS source stylesheet.
